# Node Matrix Demo

This project demonstrates GitHub Actions matrix testing for Node.js versions 16, 18, and 20.

## What this project teaches

- How to create a GitHub Actions workflow.
- How to use matrix strategy.
- How to test the same code on multiple Node.js versions.
- How to read workflow results in the GitHub Actions tab.

## Local commands

```bash
npm install
npm test
```

## Workflow file

The workflow is available at:

```text
.github/workflows/matrix-ci.yml
```
